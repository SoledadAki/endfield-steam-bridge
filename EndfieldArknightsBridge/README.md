# EndfieldArknightsBridge · 双游戏版

通过 Steam《终末地》入口选择启动终末地官服或明日方舟官服。两款游戏的时长与截图统一归入 Steam《终末地》。

在 Releases 下载 `EndfieldSteamBridge_v0.2.5_dual.zip`（官服明日方舟+终末地特别版），解压后以管理员身份运行 `EndfieldArknightsBridge.exe`。

先将终末地加入 Steam 库，安装并登录对应国服客户端。退出游戏和鹰角启动器后，确认两款官服的路径，点击“一键载入双游戏”。之后从 Steam 开始游戏。检测到启动器后会尝试补全客户端路径，未识别到时可手动选择。

Steam 使用普通权限或管理员权限均可。游戏由管理员辅助程序启动，载入不会修改 Steam 的权限、开机启动或兼容性设置。

国际服发布新版本后，Steam 会提示更新并尝试下载整个国际服。载入后会在登录 Windows 时运行一个后台辅助任务：发现 Steam 标记更新时，若没有运行游戏、启动器或本工具，它会自动重启一次 Steam 并同步版本号，Steam 便保持“开始游戏”，不会下载国际服。也可退出游戏和启动器后，在本工具中点击“同步游戏更新”手动同步。请不要在 Steam 中点击更新。国服本体请照常在鹰角启动器中更新：从 Steam 开始游戏后，若启动器显示需要下载或更新，本工具不会自动点击，请直接在启动器中更新，完成后手动点击开始游戏；关闭启动器即结束 Steam 本次运行。

升级、切换服务器或切换版本前，先在新版中点击“撤回载入国服”，再重新载入。撤回支持旧版记录，并恢复旧版曾修改的 Steam 启动设置。

Windows 10/11 x64，.NET Framework 4.8。MIT 开源协议。
