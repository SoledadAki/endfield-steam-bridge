# EndfieldArknightsBridge · 双游戏版

通过 Steam《终末地》入口选择启动终末地官服或明日方舟官服。两款游戏的时长与截图统一归入 Steam《终末地》。

在 Releases 下载 `EndfieldSteamBridge_v0.2.4_dual.zip`（官服明日方舟+终末地特别版），解压后以管理员身份运行 `EndfieldArknightsBridge.exe`。

先将终末地加入 Steam 库，安装并登录对应国服客户端。退出游戏和鹰角启动器后，确认两款官服的路径，点击“一键载入双游戏”。之后从 Steam 开始游戏。检测到启动器后会尝试补全客户端路径，未识别到时可手动选择。

Steam 使用普通权限或管理员权限均可。游戏由管理员辅助程序启动，载入不会修改 Steam 的权限、开机启动或兼容性设置。

升级、切换服务器或切换版本前，先在新版中点击“撤回载入国服”，再重新载入。撤回支持旧版记录，并恢复旧版曾修改的 Steam 启动设置。

Windows 10/11 x64，.NET Framework 4.8。MIT 开源协议。
