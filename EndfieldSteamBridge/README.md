# EndfieldSteamBridge · 终末地版

通过 Steam 启动终末地官服 / Bilibili 服，无需下载国际服。支持 Steam 计时、叠加层和截图。

在 Releases 下载 `EndfieldSteamBridge_v0.2.4_标准版.zip`，解压后以管理员身份运行 `EndfieldSteamBridge.exe`。

先将终末地加入 Steam 库，安装并登录对应国服客户端。退出游戏和鹰角启动器后，选择服务器并确认客户端路径，点击“一键载入国服”。之后从 Steam 开始游戏。检测到启动器后会尝试补全客户端路径，未识别到时可手动选择。

Steam 使用普通权限或管理员权限均可。游戏由管理员辅助程序启动，载入不会修改 Steam 的权限、开机启动或兼容性设置。

升级、切换服务器或切换版本前，先在新版中点击“撤回载入国服”，再重新载入。撤回支持旧版记录，并恢复旧版曾修改的 Steam 启动设置。

Windows 10/11 x64，.NET Framework 4.8。MIT 开源协议。
